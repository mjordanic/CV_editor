PROJECT: Merge-Request Ephemeral Environments (Lumora Health, 2023-2024)
- Every merge request gets its own short-lived environment (app + PostgreSQL + seeded data) deployed via Helm to the shared Kubernetes cluster from GitLab CI.
- Environments are destroyed automatically after merge or 48h of inactivity.
- QA and product can review features before merge; e2e tests run against the environment.
- Technologies: GitLab CI, Helm, Kubernetes, Docker, Bash, PostgreSQL.
